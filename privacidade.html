Política de Privacidade do RadarPet

Esta política explica como o MVP do RadarPet utiliza os dados informados no cadastro dos pets.

1. Dados coletados

No cadastro, o RadarPet coleta nome, espécie, raça, sexo, cor predominante, cidade, telefone, status e foto do pet.

2. Como os dados são armazenados

Nesta fase do MVP, os dados textuais ficam salvos no localStorage do navegador. Isso significa que permanecem no dispositivo até que o armazenamento local seja limpo.

3. Como a foto é tratada

A imagem selecionada não é salva diretamente no dispositivo pela aplicação. Ela é enviada ao Cloudinary e apenas a URL retornada é armazenada no cadastro.

4. Finalidade do uso dos dados

Os dados são usados exclusivamente para exibir os cards dos pets, facilitar o contato informado e manter o cadastro visível após atualizar a página.

5. Compartilhamento

O MVP não utiliza backend próprio para compartilhar dados, mas a foto enviada é processada pelo Cloudinary para gerar a URL pública da imagem.

6. Controle do usuário

Como os dados ficam no navegador, o usuário pode removê-los limpando o localStorage do site ou excluindo o cadastro em futuras melhorias do sistema.

7. Atualizações desta política

Esta Política de Privacidade pode ser atualizada sempre que o RadarPet evoluir em estrutura, integrações ou tratamento de dados.
